# AdLib SDK Documentation for LLM Context

## Overview

AdLib is a comprehensive Android ad management SDK that provides unified access to both AdMob and AppLovin MAX ad networks. It features automatic ad preloading, loading dialogs, revenue tracking, and per-ad network configuration via Remote Config.

## Architecture

### Core Components

1. **ActivityAdLoader** - Central ad preloading system with LiveData integration
2. **AdmobHelper** - AdMob ad operations facade
3. **ApplovinHelper** - AppLovin MAX ad operations facade
4. **AnalyticsTracker** - Revenue and impression tracking
5. **FirebaseRemoteConfigHelper** - Remote configuration management
6. **AdLibHiltApplication** - Base application class with AOA management

### Ad Types Supported

- **Interstitial Ads** - Full-screen ads between content
- **Rewarded Ads** - User-initiated ads with rewards
- **Banner Ads** - Standard banner advertisements
- **Collapsible Banner Ads** - AdMob-specific collapsible banners
- **Native Ads** - Custom-styled content ads
- **App Open Ads** - Launch/foreground ads

## Remote Config Structure

### Activity Configuration
```
Key Pattern: PRELOAD_{ActivityName} or PRELOAD_{ActivityName}_{FragmentName}
Value: "MAIN_IV,MAIN_RV,MAIN_BN,MAIN_NT,MAIN_AOA"
```

### Per-Ad JSON Configuration
```json
{
  "useMax": true/false,           // Required: which ad network to use
  "customId": "optional_id"       // Optional: custom ad unit ID override
}
```

### App Open Ad Configuration
```
Key: APP_AOA
Value: {"useMax": true/false, "customId": "optional_custom_aoa_id"}
```

### Fallback Ad Unit ID Keys

**AdMob:**
- `iv_ad_unit_id`, `rv_ad_unit_id`, `nt_ad_unit_id`, `bn_ad_unit_id`, `c_bn_ad_unit_id`, `aoa_ad_unit_id`

**AppLovin MAX:**
- `max_iv_ad_unit_id`, `max_rv_ad_unit_id`, `max_nt_ad_unit_id`, `max_bn_ad_unit_id`, `max_c_bn_ad_unit_id`, `max_aoa_ad_unit_id`

```kotlin
class ActivityAdLoader @Inject constructor(
    private val remoteConfigHelper: FirebaseRemoteConfigHelper,

    // Helper for automatic cleanup

}
```

## Usage Patterns

### 1. Application Setup

```kotlin
class MyApplication : AdLibHiltApplication() {
    override fun onCreateExt() {
        super.onCreateExt()
        
        // Initialize AdMob
        initAdmob(onComplete = {
            Log.d("AdLib", "AdMob initialized")
        }, testDeviceIds = listOf("TEST_DEVICE_ID"))
        
        // Initialize AppLovin MAX
        applovinHelper.initApplovin(
            context = this,
            sdkKey = "YOUR_SDK_KEY",
            testDeviceIds = listOf("TEST_DEVICE_ID"),
            onComplete = {
                Log.d("AdLib", "AppLovin MAX initialized")
            }
        )
        
        // Initialize Remote Config
        initRemoteConfig(R.xml.remote_config_default) { success ->
            Log.d("AdLib", "Remote Config initialized: $success")
            
            // Initialize App Open Ads after Remote Config is ready
            initAOA()
        }
        
        // Initialize Analytics
        initTracker("YOUR_ADJUST_TOKEN")
    }
}
```

### 2. Activity Integration

```kotlin
class MainActivity : AppCompatActivity() {
    @Inject
    lateinit var activityAdLoader: ActivityAdLoader
    @Inject
    lateinit var admobHelper: AdmobHelper
    @Inject
    lateinit var applovinHelper: ApplovinHelper

    override fun onResume() {
        super.onResume()
        // Automatically preloads ads based on Remote Config
        activityAdLoader.onActivityResumed(this)
    }
    
    private fun showInterstitial() {
        val adLiveData = activityAdLoader.getAdLiveData("MAIN_IV")
        adLiveData?.observe(this) { adObject ->
            when (adObject) {
                is InterstitialAd -> {
                    // AdMob interstitial
                    admobHelper.showInterstitial(
                        this, "iv_ad_unit_id", adObject, null,
                        object : InterstitialAdCallback() {
                            override fun onAdClosed() {
                                activityAdLoader.adShownAndShouldBeRemoved("MAIN_IV")
                            }
                        }
                    )
                }
                is MaxInterstitialAd -> {
                    // AppLovin MAX interstitial
                    applovinHelper.showInterstitial(
                        this, "max_iv_ad_unit_id", adObject,
                        object : MaxInterstitialHelper.Listener {
                            override fun onClosed() {
                                activityAdLoader.adShownAndShouldBeRemoved("MAIN_IV")
                            }
                            override fun onLoaded(interstitial: MaxInterstitialAd) {}
                            override fun onFailed(error: Any?) {}
                        }
                    )
                }
                null -> Log.w("MainActivity", "Interstitial ad not available")
            }
        }
    }
}
```

## Ad Loading Flow

1. **Activity Resumed** → `ActivityAdLoader.onActivityResumed()`
2. **Read Remote Config** → Get ad identifiers for activity
3. **Parse JSON Config** → Determine network and ad unit ID per ad
4. **Load Ads** → Call appropriate helper (AdMob/MAX)
5. **Store in LiveData** → Make ads available for observation
6. **Show Ads** → Observe LiveData and show when needed

## App Open Ad Flow

1. **Remote Config Ready** → Call `initAOA()`
2. **Get APP_AOA Config** → Parse JSON to determine network and ad unit ID
3. **Set Ad Unit ID** → Call appropriate helper's `setAppOpenAdUnitId()`
4. **Load AOA** → Call appropriate helper's `loadAOA()`
5. **Show AOA** → Call `showAOA()` when app comes to foreground

## Best Practices

1. **Always check for null** when getting LiveData
2. **Handle both ad types** (AdMob and MAX) in observers
3. **Call adShownAndShouldBeRemoved()** for one-time use ads
4. **Use existing helper methods** instead of creating new ones
5. **Test both networks** with different configurations
6. **Monitor loading times** and performance
7. **Use proper ad unit IDs** for each environment (debug/production)
8. **Initialize AOA after Remote Config** is ready
9. **Separate AOA initialization from display** for better control

## Error Handling

- **Ad not loaded**: `getAdLiveData()` returns `null`
- **Ad load failed**: LiveData is removed from cache
- **Invalid configuration**: Ad is skipped with warning logs
- **Network issues**: Handled by respective ad network SDKs
- **Loading dialog**: Automatically shown/hidden for loading states
- **AOA config null**: Falls back to AdMob with default ad unit ID

## Implementation Notes

### Loading Dialog Pattern

Both AdMob and AppLovin MAX helpers follow the same loading dialog pattern:

```kotlin
// Show method with loading dialog (when ad is null)
fun show(activity: Activity, adUnitId: String, ad: AdType?, listener: Listener?) {
    if (ad == null) {
        val loadingDialog = LoadingAdsDialog(activity)
        if (!activity.isFinishing && !activity.isDestroyed)
            loadingDialog.show()
        load(activity, adUnitId, object : Listener {
            override fun onLoaded(ad: AdType) {
                show(activity, ad, listener)
                if (loadingDialog.isShowing) {
                    loadingDialog.dismiss()
                }
            }
            override fun onFailed(error: Any?) {
                listener?.onFailed(error)
                if (loadingDialog.isShowing) {
                    loadingDialog.dismiss()
                }
            }
        })
    } else {
        show(activity, ad, listener)
    }
}
```

### App Open Ad Pattern

Both AdMob and AppLovin MAX App Open helpers follow identical patterns:

```kotlin
// State management
private var loadTime: Long = 0
private var adUnitId = ""
private var appOpenAd: AppOpenAd? = null
private var isLoadingAd = false
private var isShowingAd = false
val adLoaded = MutableLiveData<Boolean>()

// 4-hour expiration check
private fun wasLoadTimeLessThanNHoursAgo(numHours: Long): Boolean
private fun isAdAvailable(): Boolean

// Show with callback
fun showAdIfAvailable(activity: Activity, adCallback: OnShowAdCompleteListener)
```

### Revenue Tracking Pattern

```kotlin
// AdMob revenue tracking
ad.onPaidEventListener = OnPaidEventListener { adValue ->
```
